# MewCode 微信侧受限信息工具 V1 Spec

状态：已批准（含 Nominatim 指定代理修订）

## Background

MewCode 的微信桌面聊天机器人已经能够在本地 Windows 上监听白名单好友的私聊文字消息，并为每名好友维护隔离且可恢复的会话。当前微信运行时不向模型提供任何工具，也不暴露本机环境。

本次扩展需要在不削弱既有隔离措施的前提下，为微信好友开放少量只读公共信息能力：查询当前时间或地点时间、搜索及读取公开网页、查询天气。微信侧仍然不是 Coding Agent，不能借这些能力访问本机、执行命令或获得通用网络权限。

## Goals

- 每轮向微信 Agent 提供准确的本机当前时间和时区信息。
- 支持按国家、城市或其他明确地点查询当地当前时间，并正确处理夏令时。
- 支持模型在必要时自动搜索公开网页或读取好友提供的公开链接。
- 支持查询指定地点的当前天气、短期逐小时预报和七日预报。
- 通过程序强制的独立白名单，仅向微信运行时开放本次批准的只读信息能力。
- 控制外部请求次数、费用、隐私泄露、网页提示注入和会话存储膨胀。
- 保持现有微信消息处理、好友隔离、MewCode TUI 和 Coding Agent 权限不受影响。

## Functional Requirements

### F1：微信侧工具白名单

- 微信运行时只允许使用四类专用能力：当前时间／地点时间、网页搜索、网页读取和天气查询。
- 白名单必须由程序强制执行，不能依赖系统提示或模型自律。
- 微信好友不能调用 Bash、文件读写、代码编辑、目录搜索、任意 HTTP 请求、浏览器、MCP、Skills、Sub-agent、Hook 或本机应用控制能力。
- 网页和天气能力只能访问各自批准的外部服务或通过安全校验的公开网页。
- 模型请求未注册的能力时，系统不得执行该请求。
- 微信侧白名单不得改变普通 MewCode TUI 与 Coding Agent 的现有工具和权限。

### F2：每轮时间环境

- 每次处理微信好友的新消息时，系统应注入本机当前日期、时间和 IANA 时区。
- 时间信息应在该轮开始时重新生成，不得沿用上一轮的时间文本。
- 注入内容不得暴露项目路径、用户名、系统凭据或其他本机环境信息。
- 即使已经注入时间，模型仍可使用专用时间能力取得更新后的当前时间。

### F3：地点时间查询

- 用户询问某个明确城市或地点的时间时，系统应按该地点的实际时区返回当前当地时间。
- 用户只提供国家名称时，系统应按该国首都所在地的时区回答；例如“美国现在几点”按华盛顿特区处理。
- 地点存在合理歧义时，系统应返回候选地点并要求用户确认，不得由模型擅自猜测。
- 时间结果应包含规范地点、当地日期、当地时间、时区和相对本机日期差异，并正确处理夏令时。
- 地点与时区的确定应由受控地点解析和时区数据完成，不能让模型自行推测时区。
- 常见国家、首都和地点别名应优先在本地解析；任意地点解析可低频使用公共 Nominatim 服务。
- 对公共 Nominatim 的使用应遵守每秒最多一次请求、可识别客户端标识和本地缓存要求。
- 公共 Nominatim 可使用本机显式配置的 HTTP 或 HTTPS 代理；未配置代理时保持直接连接，不得自动继承未声明的系统代理。
- 已配置代理时，Nominatim 请求只能通过该代理访问固定的官方服务地址，不得静默回退到直连，也不得允许模型选择代理、目标地址、请求头或认证信息。
- Nominatim 代理不得用于 Open-Meteo、Tavily、公开网页读取或其他网络请求，不得把受限信息工具变成通用代理访问能力。
- 对外使用 Nominatim 解析结果时应清楚标注地点数据来自 OpenStreetMap。
- 地点解析结果可长期缓存；网络不可用时优先使用已有缓存，没有可靠结果时应明确查询失败。

### F4：网页自动搜索

- 网页搜索使用 Tavily 免费套餐的 Basic 搜索能力，不启用高级搜索、按量付费或其他付费回退。
- 每轮最多执行两次网页搜索，每次最多向模型提供五条结果；程序必须执行硬限制。
- 模型可在用户明确要求搜索、问题涉及最新或易变化信息、已有知识不足以可靠回答时自动搜索。
- 新闻、价格、政策、比赛、产品版本和人物职位等易变化信息应优先搜索核实。
- 日常闲聊、写作、改写、翻译、已有文本总结、数学计算和纯逻辑问题不应为丰富回答而搜索。
- 当前时间和普通天气问题应优先使用对应专用能力，不得无故消耗网页搜索额度。
- 免费额度耗尽时，系统应明确提示本月网页查询额度已用完，不得自动切换搜索来源或产生费用。

### F5：公开网页读取

- 用户发送公开网页链接并要求查看或总结时，机器人可以直接读取该链接。
- 网页读取仅允许公开的 HTTP 或 HTTPS 地址。
- 初始地址和每次重定向后的最终地址都必须校验，不得访问本机、回环地址、局域网、私有地址、链路本地地址或其他非公网目标。
- 网页请求不得携带浏览器 Cookie、登录态、认证头或其他本机凭据。
- 第一版只支持 HTML 和纯文本；单次下载上限为 2 MiB，提取正文上限为 50,000 字符。
- 正文超过上限时应安全截断，并让模型知道内容不完整。
- 每轮最多读取五个页面，不能通过重定向或重复调用绕过限制。
- 第一版不启动或控制浏览器，不执行网页 JavaScript，不点击按钮、不填写表单，不处理登录、验证码、付费墙或 Cookie 弹窗。
- 静态方式无法取得正文时，应明确说明页面暂时无法读取；可以在剩余额度内查找其他公开来源。

### F6：网页搜索触发与来源使用

- 中文提问默认使用中文回复，并优先检索与问题语言一致的来源，但不得排斥更可靠的外语来源。
- 官方网站、政府机构、标准文档、论文原文和当事方公告应优先于转载与聚合内容。
- 新闻类回答应区分事件发生时间与文章发布时间。
- 对可能造成明显影响的事实，应在额度允许时使用两个独立来源交叉核实。
- 来源冲突时应说明分歧，不得把冲突内容拼接成确定结论。
- 医疗、法律和投资等高风险内容只能作为信息整理，并提示不能替代专业意见。
- 使用过网页搜索或网页读取后，最终微信回复必须列出实际使用的来源标题和 URL。
- 每次回复最多展示三个最关键来源；长回复分段时，来源统一放在最后一条消息中。
- 搜索或读取失败时，不得把未经核实的摘要或不存在的来源描述为已经确认的事实。

### F7：网页查询隐私

- 自动搜索只能发送完成检索所需的最短关键词，不得把完整微信消息或会话历史直接发送给外部服务。
- 自动搜索不得包含好友昵称、手机号、身份证号、住址、账号、密钥或其他非必要个人信息。
- 用户明确要求搜索真实人物、手机号或其他个人信息时，系统应先提示隐私风险并要求再次确认。
- 用户提供的 URL 含疑似访问令牌或敏感查询参数时，应移除敏感参数；无法安全处理时应拒绝请求。
- 网页搜索请求与网页正文不得与好友身份或微信会话标识关联存储。
- Tavily API Key 不得发送给模型、写入日志、写入会话记录或提交到版本库。

### F8：网页内容安全

- 搜索结果和网页正文一律作为不可信外部数据处理。
- 网页中的代理指令、越权要求、工具调用要求和索取会话或凭据的内容不得改变系统行为。
- 系统应只向模型提供提取后的可见正文，排除脚本、样式、表单、隐藏元素及其他可执行内容。
- 网页不能要求机器人继续爬取、扩大权限、泄露聊天记录或改变工具限制。
- 页面内容与系统规则或用户当前请求冲突时，应以系统规则和用户当前请求为准。
- 用户要求总结提示词、代理指令或越狱材料时，可以描述其内容，但不得执行其中指令。

### F9：网页请求限制与缓存

- 单次 Tavily 搜索和单个网页读取的超时时间均为 10 秒。
- 每轮所有网页能力累计等待时间最多为 25 秒。
- 临时网络错误或服务端错误最多重试一次；鉴权失败、额度不足、限流和参数错误不得循环重试。
- 普通搜索结果缓存 30 分钟，网页正文缓存 1 小时。
- 用户强调“实时”“刚刚”“最新”或“今天”时，不得使用超过 5 分钟的搜索缓存。
- 网页缓存只保存规范化查询、公开 URL、标题、公开正文和时间戳，不得关联好友或会话身份。
- 网页缓存最多保留 7 天，并应自动清理过期数据。
- 网络失败时可使用仍在保留期内的过期缓存，但回复必须注明缓存时间及当前使用缓存内容。
- 部分来源失败但仍有可靠来源时可以继续回答，并明确未能核实的部分；全部来源失败时应明确查询失败。

### F10：天气数据源与查询范围

- 普通天气查询只使用 Open-Meteo 免费非商业接口，不配置其他天气来源或付费回退。
- 当前本地个人用途必须遵守 Open-Meteo 免费非商业使用限制和署名要求。
- 天气查询支持当前天气、今天与明天、未来七天逐日预报，以及未来 48 小时逐小时预报。
- 可回答的天气要素包括温度、体感温度、天气状况、湿度、降水概率、降水量、风速、风向、当日最高与最低温、日出和日落时间。
- 第一版不查询历史天气、气候统计、七天以后的长期趋势、台风路径、雷达图、卫星图或官方灾害预警。
- 天气查询每次都应请求最新数据，不缓存天气响应，也不得返回上一次查询结果。
- 地点解析结果可以复用时间能力已有的地点缓存。

### F11：天气地点、单位与回复

- 用户明确提供地点时，应查询该地点；后续紧邻追问可沿用当前对话中刚刚明确的地点。
- 用户未提供地点且上下文没有明确地点时，应追问城市，不得按好友昵称、IP、本机位置或机器人所在地推测。
- 地名存在歧义时，应要求用户确认候选地点。
- 天气查询只应向地点解析服务发送城市、区县、乡镇或公开地标名称；完整住址、小区楼栋和门牌应尽量缩减到区县或城市。
- 无法安全缩减精确住址时，应追问城市名称，不得把完整住址发送给外部服务。
- 天气服务只接收解析后的经纬度、时区和所需天气字段，不接收好友身份或会话历史。
- 默认单位为摄氏度、公里／小时和毫米；用户明确要求时可以返回其他常用单位。
- 所有日期和时间均按查询地点的当地时区显示；天气状况应转换为简洁中文描述。
- 回复应显示规范地点、数据对应的当地日期和时间，只呈现与问题有关的字段，并注明“天气数据：Open-Meteo”。
- 回复不得展示包含经纬度的原始请求 URL。
- 明显恶劣天气可以附加一般安全提醒，但不得声称该提醒是官方预警。

### F12：天气路由与失败处理

- 普通当前天气和天气预报问题只使用天气能力，不使用网页搜索替代。
- 官方预警、台风动态等实时公告问题应使用网页搜索，并优先选择官方气象来源。
- 穿衣、出行等建议应先取得结构化天气数据，再由模型给出一般性建议。
- 单次天气请求超时 10 秒；临时网络错误或服务端错误最多重试一次，限流和参数错误不得重试。
- 天气查询失败后不得用网页结果替代普通预报，不得使用旧天气数据或编造结果。
- 查询失败时应明确回复天气服务暂时不可用，并保持微信机器人继续处理后续消息。

### F13：工具结果与会话存储

- 用户原消息和机器人的最终回复继续按现有微信会话规则保存。
- 原始网页搜索结果、网页全文、Tavily 返回体和天气服务原始返回体不得写入好友会话档案或长期记忆。
- 同一轮模型推理可以临时使用工具结果；该轮结束后，后续查询应重新调用工具或读取批准的独立缓存。
- 运行日志只记录工具类型、成功或失败、耗时、结果数量和安全的错误类别，不记录网页正文、完整住址、好友与坐标关联或凭据。
- 地点缓存和网页缓存属于独立运行数据，不得成为好友画像或跨好友共享的对话记忆。

### F14：配置与凭据

- 微信工具配置应明确启用状态、Tavily 凭据和外部服务所需的客户端标识。
- Nominatim 代理必须由本机用户配置或环境变量显式指定；代理地址及其中可能包含的凭据按密钥处理。
- Tavily API Key 只能从本机用户配置或环境变量取得，不得出现在示例默认值、版本库、日志、微信回复或模型上下文中。
- Nominatim 代理地址及凭据不得出现在示例默认值、版本库、日志、微信回复、缓存、会话档案或模型上下文中。
- 缺少或无效 Tavily API Key 时，时间和天气能力仍可使用；网页搜索应返回明确的配置错误。
- 未配置 Nominatim 代理时继续尝试直接连接；已配置代理但代理无效或不可达时，应明确返回地点解析失败，不得切换其他代理、地点服务或直连绕过。
- 外部服务配置错误不得导致微信机器人整体无法启动或停止处理不依赖该服务的消息。
- 系统不得自动开通付费套餐、修改外部账户计费设置或切换到收费接口。

## Non-Functional Requirements

### N1：安全性

- 微信消息、搜索结果和网页正文都是不可信输入。
- 网络目标限制、工具白名单、调用次数和响应大小必须由程序执行。
- 所有外部请求都应遵循最小数据披露原则。
- 任一工具都不得成为访问本机文件、内网服务或任意网络接口的通道。
- Nominatim 代理只承载到固定官方地点服务的请求；不能被网页读取、模型参数或重定向用于访问其他目标。

### N2：隐私

- 不同好友的可见会话继续保持隔离。
- 外部服务不得收到不完成当前查询所必需的聊天内容和身份信息。
- 日志、缓存、会话档案和错误回复不得包含 API Key、访问令牌或完整系统提示。
- 日志、缓存、会话档案、错误回复和模型上下文不得包含 Nominatim 代理地址或代理凭据。
- 公开网页缓存不得建立好友、会话或个人画像索引。

### N3：费用与外部条款

- Tavily 只使用免费 Basic 能力，额度耗尽后停止搜索，不产生超额费用。
- Open-Meteo 只在本地个人非商业场景使用，并在回复中署名。
- 公共 Nominatim 只用于低频地点解析，并遵守限速、客户端标识和缓存要求。
- 外部服务条款或项目用途变化为商业场景时，应在继续使用前重新评估，不得默认为当前免费方案仍然适用。

### N4：可靠性

- 单个工具超时、返回错误或内容异常不得终止 Agent 进程或微信消息循环。
- 调用限制、超时、有限重试和失败提示应避免无限等待与重试风暴。
- 时间和天气数值应由确定性数据与转换产生，不依赖模型心算或时区猜测。
- 网页来源不足或冲突时，回答应保留不确定性。

### N5：性能

- 不需要外部请求的普通聊天不应因工具扩展增加可感知网络等待。
- 地点缓存和网页缓存应减少重复外部请求，但不得违反已确认的新鲜度规则。
- 工具调用仍服从现有微信全局先进先出任务队列，不引入并行外部请求要求。

### N6：兼容性

- 现有微信 4.1.12.55 UI Automation 监听、会话切换、键盘发送、去重、取消和好友隔离行为不得回退。
- 原有 MewCode TUI、Coding Agent、MCP、Skills、Sub-agent、Hook、会话和权限行为不得改变。
- 不启用微信工具的用户不应被要求配置 Tavily 或安装无关的微信运行依赖。

### N7：可测试性

- 时间、地点解析、缓存新鲜度、调用限额、地址校验、隐私过滤、天气字段转换和工具路由应能在不连接真实外部服务和真实微信的情况下测试。
- 外部服务集成应能够使用受控响应验证成功、超时、限流、鉴权失败、服务端失败、歧义地点和恶意网页等情形。
- 自动化测试不得向真实好友发消息，也不得消耗真实 Tavily 额度。

## Out of Scope

第一版不包含：

- Bash、文件读写、代码编辑、目录搜索和任意 HTTP 请求。
- 浏览器自动化、登录网页、表单提交、验证码处理和付费墙绕过。
- PDF、图片、音频、视频、压缩包、可执行文件和其他网页附件解析。
- 网页抓取任务、站点递归爬取、批量下载和持续监控。
- 通过网页内容动态安装工具、Skills、MCP 或子智能体。
- Tavily Advanced、Research、付费套餐或其他搜索服务回退。
- 商业使用 Open-Meteo 免费接口。
- 历史天气、气候分析、长期天气趋势、雷达、卫星和台风路径。
- 把普通天气预报描述成当地气象部门的官方预警。
- 根据 IP、微信资料或本机位置推断好友所在地。
- 保存网页全文到会话历史、把工具结果写入长期记忆或建立好友画像。
- 改变 Chapter 13 已确定的本地 Windows、微信版本、私聊文字、白名单和全局串行队列边界。
- 把指定代理开放给 Tavily、Open-Meteo、公开网页读取、模型或其他通用网络请求。

## Acceptance Criteria

### AC1：权限隔离

- 微信模型请求只暴露时间、网页搜索、网页读取和天气四类能力。
- 微信好友要求执行命令、读取文件、调用 MCP、启动浏览器或创建子智能体时，操作不会执行。
- 普通 MewCode TUI 仍保留其原有工具和权限。

### AC2：每轮时间与地点时间

- 连续两轮微信请求分别收到各自生成的本机当前日期、时间和时区环境信息。
- 询问“美国现在几点”时按华盛顿特区时区返回；询问明确城市时按城市时区返回。
- 处于夏令时的地点返回正确偏移；歧义地点要求用户确认而不是猜测。
- 地点解析失败时返回明确错误，不由模型编造时区。
- 使用 Nominatim 解析并展示地点时可以观察到 OpenStreetMap 署名。
- 配置指定代理后，Nominatim 通过该代理成功解析地点；未配置时仍可直接连接。
- 指定代理不可达时返回明确的地点解析失败，并且不会静默直连或切换其他地点服务。

### AC3：自动网页搜索

- 最新信息问题可由模型自动搜索，普通闲聊不会无故触发搜索。
- 同一轮第三次搜索请求被程序拒绝，每次返回模型的搜索结果不超过五条。
- Tavily 额度耗尽或凭据无效时给出明确错误，不调用付费或备用搜索服务。
- 当前时间和普通天气问题优先使用专用能力，不消耗搜索额度。

### AC4：公开网页读取安全

- 用户提供的普通公开 HTML 或纯文本链接可以被读取和总结。
- 本机、内网、私有地址、非 HTTP(S) 协议及重定向到这些目标的请求全部被拒绝。
- 超过 2 MiB、正文超过 50,000 字符或类型不受支持的内容被拒绝或按规则截断。
- 第六个页面读取请求被程序拒绝。
- 动态页面、登录页和验证码页无法静态读取时返回明确说明，不启动浏览器处理。

### AC5：网页限时与缓存

- 普通搜索结果在 30 分钟内、网页正文在 1 小时内可命中缓存。
- “最新”查询不会使用超过 5 分钟的搜索缓存。
- 网页工具累计等待达到 25 秒后停止继续等待。
- 网络失败时使用过期缓存会明确显示缓存时间；缓存不存在且所有来源失败时不编造答案。
- 超过 7 天的网页缓存可以被自动清理。

### AC6：来源与内容可信度

- 使用网页能力的最终回复展示不超过三个实际使用的来源标题和 URL。
- 长回复的来源出现在最后一条微信消息中。
- 恶意网页要求泄露对话、调用工具或忽略系统规则时，相关指令不会被执行。
- 来源冲突或不足时，回复明确说明不确定性；高风险信息带有适当提示。

### AC7：网页隐私

- 自动搜索请求不包含完整微信消息、会话历史、好友昵称或非必要个人信息。
- 查询真实个人敏感信息前要求用户再次确认。
- 含疑似令牌且无法安全清理的 URL 被拒绝。
- API Key 不出现在模型请求、微信回复、日志、会话档案或版本库中。
- Nominatim 代理地址和凭据不出现在模型请求、微信回复、日志、缓存、会话档案或版本库中。

### AC8：当前天气与预报

- 查询明确地点的当前天气时，返回当地时间下的相关天气字段和 Open-Meteo 署名。
- 可以回答未来 48 小时的逐小时问题和未来七天的逐日问题。
- 用户未给地点且上下文无地点时会被追问；紧邻追问可以沿用刚刚明确的地点。
- 单位默认使用摄氏度、公里／小时和毫米，明确要求其他单位时返回正确换算值。
- 连续两次相同天气查询都会请求最新天气数据，不命中天气响应缓存。

### AC9：天气隐私与路由

- 完整住址不会原样发送给地点或天气服务；无法缩减时要求用户提供城市。
- Open-Meteo 请求不包含好友身份、微信消息或会话历史，回复不暴露原始坐标 URL。
- 普通天气问题不触发网页搜索；官方预警或台风动态问题使用网页搜索及官方来源。
- Open-Meteo 失败时不以网页结果、旧天气或模型猜测替代普通预报。

### AC10：失败隔离

- 时间、网页或天气能力的超时和错误只影响当前工具调用，不会终止微信机器人。
- 临时网络或服务端错误最多重试一次，鉴权、限流和参数错误不循环重试。
- 工具失败后，后续微信消息仍能正常进入处理队列。
- 错误回复不包含堆栈、凭据、完整系统提示或本机敏感路径。

### AC11：存储边界

- 用户消息和最终回复按现有规则保存在对应好友会话中。
- 原始搜索结果、网页全文、Tavily 返回体和天气原始返回体不出现在会话档案或长期记忆中。
- 网页与地点缓存不保存好友或会话关联。
- 默认运行日志不包含网页正文、完整住址、好友与坐标关联或凭据。

### AC12：兼容与回归

- Chapter 13 的微信自动化测试继续通过，真实微信收发行为不因工具扩展改变。
- MewCode 原有自动化测试继续通过。
- 自动化测试不访问真实 Tavily、Nominatim、Open-Meteo 或真实微信好友。
