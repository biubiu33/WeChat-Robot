# MewCode 微信天气改用网页搜索 Spec

状态：已批准

## Background

微信侧当前提供独立天气能力，依赖地点解析后访问专用天气数据源。国内城市可能因地点候选歧义而无法进入天气查询，而现有网页搜索与网页读取已经能够取得公开天气信息。为减少专用链路、配置和维护成本，本次彻底移除独立天气能力，统一使用受限网页工具回答天气问题。

## Goals

- 微信侧不再暴露或调用独立天气能力，也不再访问 Open-Meteo。
- 当前天气、短期预报、穿衣与出行天气建议均自动使用现有网页搜索，必要时读取公开结果页。
- 天气网页查询继续遵守现有搜索限次、免费额度、隐私、来源质量和网页安全边界。
- 保持当前时间／地点时间、普通网页搜索、网页读取及微信聊天能力不变。

## Functional Requirements

### F1：移除独立天气能力

- 微信模型每轮只可使用当前时间／地点时间、网页搜索和网页读取三类公共信息能力。
- 系统不得再调用 Open-Meteo 或其他专用天气接口。
- 独立天气能力的参数、返回结构、单位转换、天气代码转换、缓存规则和专用署名不再属于产品能力。
- 既有好友会话中的历史最终回复应继续可读；已经脱敏的旧天气工具中间记录不得导致恢复失败。

### F2：天气问题自动走网页工具

- 用户询问当前天气、今天／明天预报、未来天气、降雨、温度、风力或基于天气的穿衣与出行建议时，机器人应自动搜索网页，无需再次征求普通联网确认。
- 搜索只发送完成当前问题所需的最短地点、日期范围和天气关键词，不发送好友身份、完整聊天历史或其他无关内容。
- 用户提供公开天气页面时，可按既有安全规则直接读取该链接。
- 搜索摘要不足以可靠回答时，可在每轮网页读取限额内读取搜索结果中的公开静态页面。
- 用户未提供地点，且当前好友的对话上下文中没有唯一明确地点时，应先追问城市或地区，不得依据 IP、好友资料或其他好友会话猜测。
- “那明天呢”等紧邻追问可以使用当前好友对话中刚刚明确的地点；不得跨好友复用地点。

### F3：天气来源与回答

- 天气资料优先选择国家或地方气象部门、政府公共服务、主流天气服务和其他可识别来源。
- 回复应明确资料对应的地点和日期，并在末尾列出本回合实际使用的网页来源。
- 来源之间存在明显差异时，应说明差异，不得把单一网页结果包装成确定事实。
- 官方预警、台风动态和灾害信息仍应优先引用气象部门或政府来源，不得把一般网页天气描述成官方预警。
- 网页搜索或读取失败、Tavily Key 缺失、免费额度耗尽或来源不足时，应明确说明暂时无法查询，不得使用旧的专用天气结果、模型猜测或未批准数据源补全。

### F4：费用与调用边界

- 天气查询与其他网页查询共享现有每轮最多两次搜索、每轮最多五页读取和累计等待限制。
- 天气搜索使用现有 Tavily Basic 免费模式和本地每月 1,000 credits 上限，不启用超额付费、Advanced 或其他搜索服务回退。
- 天气网页搜索与读取继续使用既有缓存策略；不新增天气专用缓存或天气专用数据库状态。

### F5：保留的地点时间能力

- Nominatim、地点缓存、指定代理和国家首都数据继续仅为地点时间能力服务。
- 删除独立天气能力不得影响本机时间、国家首都时间、具体城市时间、时区和夏令时查询。
- Nominatim 指定代理仍不得扩展到网页搜索或网页读取。

## Non-Functional Requirements

- 微信侧工具权限必须保持只读，并由三工具白名单强制执行。
- 不得新增浏览器自动化、天气 SDK、搜索 SDK 或其他运行依赖。
- 天气网页内容继续视为不可信输入，不得执行页面指令或扩大工具权限。
- 删除天气能力后，微信监听、UIA、好友隔离、会话恢复、取消和回复分段行为不得回退。
- 自动化测试不得访问真实微信、Tavily、Nominatim 或其他外部服务。

## Out of Scope

- 保留隐藏的天气工具或 Open-Meteo 备用路径。
- 提供结构化天气 API、固定天气字段、单位换算或天气代码转换保证。
- 动态浏览器、登录网页、验证码、PDF、图片、雷达图或卫星图读取。
- 新增付费搜索、第二搜索源或绕过 Tavily 免费额度。
- 修复或增强天气用途之外的地点候选排序。

## Acceptance Criteria

### AC1：三工具权限边界

- 启用微信公共信息能力后，模型请求精确只包含当前时间／地点时间、网页搜索和网页读取三个工具。
- 模型尝试调用旧天气工具时无法执行，也不能通过系统提示或好友消息重新注册。

### AC2：天气自动网页查询

- 测试好友询问明确城市的当前或未来天气时，机器人自动使用网页搜索，无需普通联网确认。
- 搜索参数只包含最短必要天气查询，不包含好友名、Session ID 或完整对话。
- 缺少地点且上下文没有唯一地点时先追问；同一好友紧邻追问可沿用已明确地点，另一好友不能继承。

### AC3：来源与失败处理

- 天气回复包含实际网页来源、地点和日期；优先选择气象部门、政府或可识别天气来源。
- 来源冲突时明确说明，普通天气信息不得冒充官方预警。
- 搜索不可用、额度耗尽或来源不足时返回明确失败，不调用专用天气服务，也不编造天气数据。

### AC4：彻底移除专用天气链路

- 运行代码、工具定义、用户配置和用户文档中不再存在可调用的 Open-Meteo 或独立天气路径。
- 新安装包不包含独立天气实现；运行时不会向 Open-Meteo 发起请求。
- 不存在天气专用缓存、地点跟随状态或 Open-Meteo 署名后处理。

### AC5：费用、安全与兼容性

- 天气搜索计入既有每轮和每月 Tavily 限额，不启用付费或其他搜索源回退。
- 网页 SSRF、内容类型、大小、重定向、隐私确认、来源过滤和不可信内容规则继续生效。
- 当前时间／地点时间及 Nominatim 指定代理继续工作；微信和完整项目回归测试通过。
