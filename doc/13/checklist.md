- [x] 提供独立的微信机器人启动命令，启动过程不打开或依赖 TUI。（验证：单独运行微信命令并观察进程界面）
- [x] 原有 MewCode Agent 循环被微信入口复用，没有实现第二套 Agent 循环。（验证：代码审查调用链并运行集成测试）
- [x] 微信配置完全位于 MewCode 自有配置中，未读取 fake-wx-account 配置或默认值。（验证：代码搜索和配置测试）
- [x] 微信适配只声明兼容桌面客户端 4.1.12.55，必要控件定位来自本机只读探测。（验证：只读探测记录和代码审查）
- [x] 消息监听只输出启动后新增的私聊文字事件。（验证：快照差异自动化测试）
- [x] 白名单、消息类型和重名判断均在调用模型前完成。（验证：假模型调用计数测试）
- [x] 同一事件只能首次登记一次，处理状态和好友 Session 绑定可持久恢复。（验证：SQLite 关闭重开测试）
- [x] 每名唯一白名单好友使用独立、可恢复的 MewCode Session。（验证：双好友 runtime 测试）
- [x] 微信 Agent 没有 Bash、文件、MCP、Skills、Sub-agent、Hook 和长期记忆能力。（验证：模型工具定义为空且相关加载器未被调用）
- [x] 入站任务由单个全局 FIFO 消费者串行处理。（验证：并发入队顺序测试）
- [x] `/cancel` 只影响同一好友当前任务，且不进入 Agent 会话。（验证：跨好友和同好友取消测试）
- [x] 回复只使用最终文本，空回复不发送，长回复按配置顺序分段。（验证：假发送器测试）
- [x] 每次真实发送前重新定位并确认原会话，无法确认时安全失败。（验证：目标变化测试）
- [x] 会话切换和文字发送均不调用鼠标点击，焦点或唯一性异常时安全失败。（验证：键盘 UIA 测试和本机鼠标坐标观察）
- [x] 单条消息失败、超时或取消不会终止机器人主循环。（验证：故障注入后继续处理下一条消息）
- [x] 日志和文档覆盖启动、配置、运行、安全边界与人工验证方式。（验证：人工审阅 README 和示例日志）

## Automated Behavior Checks

- [x] 合法微信配置能加载，非法类型、空白名单、未知 Provider 和越界数值被明确拒绝。（验证：运行 `pytest tests/test_wechat_config.py -q`）
- [x] 未配置微信段时，现有 MewCode 配置与 TUI 行为保持兼容。（验证：运行配置回归测试）
- [x] 同一消息指纹重复出现时只登记一次。（验证：运行 `pytest tests/test_wechat_store.py -q`）
- [x] Session 绑定重复写入幂等、冲突写入失败，并能在重启状态库后恢复。（验证：运行状态库测试）
- [x] 启动基线不会发出历史消息事件，新增气泡才会产生候选事件。（验证：运行 `pytest tests/test_wechat_uia_driver.py -q`）
- [x] 出站气泡、群聊、图片、语音、文件、视频、卡片和系统通知不会产生入站事件。（验证：运行合成快照过滤测试）
- [x] 非白名单、重名和重复消息均不会调用模型。（验证：运行 `pytest tests/test_wechat_bot.py -q`）
- [x] 两名好友的消息按入队顺序串行完成，后到任务不会覆盖活动任务。（验证：运行 FIFO 并发测试）
- [x] 同好友 `/cancel` 可以结束活动任务，其他好友不能取消该任务，取消后队列继续。（验证：运行取消测试）
- [x] 目标会话变化时不发送，目标匹配时分段回复保持原顺序。（验证：运行假 UIA 发送器测试）
- [x] 键盘搜索只在搜索框焦点、精确值和唯一结果均成立时按 Enter，键盘发送只在聊天输入框获得焦点时按 Enter。（验证：运行 UIA 客户端合成测试）
- [x] 模型失败只产生一次失败结果，下一条消息仍正常处理。（验证：运行故障恢复测试）
- [x] 两名好友分别创建和恢复不同 Session，任一好友上下文不包含另一好友内容。（验证：运行 `pytest tests/test_wechat_runtime.py -q`）
- [x] 模型收到的工具定义为空，聊天中的命令或权限诱导不会触发任何本地操作。（验证：运行零工具安全测试）
- [x] 超时和取消均能终止当前 Agent 任务并关闭当前会话 Writer。（验证：运行 runtime 生命周期测试）

## End-To-End Scenarios

- [x] 场景 1：启动机器人时已有历史消息，进入监听后不回复任何历史消息。（验证：启动前在授权测试会话保留可见文字，观察无发送）
- [x] 场景 2：白名单测试联系人发送一条新私聊文字，5 秒内进入处理流程，并只向该会话发送一组最终回复。（验证：时间戳和微信界面观察）
- [ ] 场景 3：非白名单联系人发送文字，不调用模型且不发送回复。（验证：Provider 调用日志计数和微信界面观察）
- [ ] 场景 4：白名单联系人要求执行命令、读取文件或修改文件，机器人只能文字回答，本机没有对应操作。（验证：隔离测试目录、进程记录和回复内容）
- [ ] 场景 5：机器人发送的回复不会再次触发 Agent；连续观察和切换会话后也不会重复回复。（验证：模型调用次数和微信界面观察）
- [ ] 场景 6：群聊消息和私聊中的图片、语音、文件或系统通知均不触发 Agent。（验证：逐类发送测试并检查模型调用次数）
- [ ] 场景 7：好友 A 和好友 B 分别提供不同上下文，后续回答只使用各自内容；重启机器人后隔离仍保持。（验证：双联系人问答及重启复测）
- [ ] 场景 8：好友 A 和好友 B 近乎同时发送消息，第二条等待第一条结束并按入队顺序回复。（验证：使用可观察的慢模型响应并核对日志顺序）
- [ ] 场景 9：好友 A 的任务运行时，好友 A 发送 `/cancel` 可取消；好友 B 的 `/cancel` 不能取消 A；随后消息继续处理。（验证：双联系人取消测试）
- [ ] 场景 10：Agent 生成期间人工切换到其他联系人，回复仍回到原会话；若无法复核原目标，则不向任何错误会话发送。（验证：两次人工切换测试）
- [ ] 场景 11：生成超过单段上限的回复，各段按顺序发送且内容无重排。（验证：授权测试好友长回复测试）
- [ ] 场景 12：模拟一次模型请求失败，好友只收到一次简短失败提示，后续新消息仍能正常回复。（验证：临时故障 Provider 或测试开关）
- [x] 场景 13：从一个授权好友无鼠标切换到另一个授权好友并发送固定文字，鼠标坐标不变且文字只出现在目标会话。（验证：本机 UIA 操作前后坐标和会话文本观察）
