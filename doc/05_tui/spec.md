# TUI 展示优化 Spec

## 背景

MewCode 已具备多轮对话、工具调用、Agent Loop、计划模式和取消能力，但当前终端界面将用户消息、助手文本、工具调用、工具结果与错误信息连续写入同一日志。用户很难快速辨认每轮任务的边界，也无法在不被长工具结果干扰的情况下浏览执行过程。流式写入还会干扰正在查看历史内容的用户。

本次仅优化 TUI 的信息层级、视觉样式和交互展示。Agent、Provider、工具执行、会话历史及其行为保持不变。本方案独立存放在 `doc/05_tui/`，不属于后续正式功能章节。

## 目标

- 让每一个用户问题成为清晰可扫描的对话回合起点。
- 以克制、一致的样式区分用户、助手、工具、结果、错误和取消状态。
- 默认收起工具结果，降低长输出对主对话流的干扰，同时让用户可主动查看摘要。
- 保持输入区固定在终端底部，改善流式输出时的历史浏览体验。
- 不改变任何 Agent 核心逻辑、工具调用语义或 Provider 请求。

## 功能需求

- F1: 用户回合高亮
  每条用户消息必须以明显的背景或边界高亮呈现，并与前一回合保留稳定间距。高亮区域应同时包含用户标识和完整问题文本，使用户能够快速定位每轮任务的起点。

- F2: 语义化时间线样式
  对话时间线必须使用一致且克制的视觉语言区分以下内容：
  1. 用户消息。
  2. 助手文本。
  3. 工具调用。
  4. 工具结果。
  5. 错误。
  6. 取消与其他通知。

  样式应依靠有限的颜色、缩进、标题和边界表达层级，不能使用大面积装饰、复杂渐变或影响终端阅读的动态效果。

- F3: 可折叠工具结果
  工具调用完成后，时间线默认只显示工具名称、执行状态和安全参数摘要。对于 `bash`，摘要显示实际执行的命令；对于文件与搜索工具，摘要只显示安全的路径、模式或搜索词，不能显示写入内容等敏感参数。

  工具结果正文默认折叠。用户点击对应工具行可展开或收起结果摘要；展开内容应保留成功或错误状态的视觉区分，并继续受既有的结果截断限制。

- F4: 固定多行输入区
  输入区始终固定在主界面底部，保持 Enter 提交、Alt+Enter 换行的既有行为。空闲、流式、取消恢复和错误恢复后，输入区的可编辑状态与焦点行为必须保持正确。

- F5: 条件自动滚动
  写入新的用户消息、流式文本、工具事件或工具结果时，界面必须判断用户是否已停留在日志底部：
  - 用户位于或接近日志底部时，自动跟随最新内容。
  - 用户已向上滚动查看历史时，不得强制跳回底部或改变其阅读位置。
  - 用户主动回到底部后，后续内容恢复自动跟随。

- F6: 流式活动区
  流式状态下，界面应提供与最终时间线样式一致的临时活动区，显示当前回复文本、执行中的工具或等待状态、耗时与 Agent 迭代进度。回合完成、错误或取消后，临时区清空，最终内容保留在时间线中。

- F7: 保持现有工作流
  Provider 选择、普通对话、`/plan`、`/do`、Esc/Ctrl+C 取消、状态栏 token 统计、工具事件顺序和会话历史必须保持现有行为。展示层不得新增用户确认步骤、权限模型或网络请求。

## 非功能需求

- N1: 终端可读性。界面应在常见终端宽度下避免截断关键标题、覆盖输入区或让长文本破坏布局。
- N2: 交互可用性。鼠标点击可用于展开/收起工具结果；没有鼠标时，界面仍必须保持正常对话、滚动和输入能力。
- N3: 性能。长对话和连续流式更新不得造成可感知的界面冻结；折叠工具结果应减少默认渲染噪声。
- N4: 安全性。展示优化不得引入 API Key、文件写入正文、完整命令输出以外的敏感数据泄露；安全参数摘要规则继续生效。
- N5: 兼容性。继续使用现有 Textual 与 Rich 依赖，不增加前端框架或浏览器运行时。
- N6: 质量。新增展示逻辑应具备自动化测试，现有 TUI、Agent、Provider 测试继续通过。

## 不做的事

- 不修改 Agent Loop、Provider 接口、工具注册、工具执行、会话历史或系统提示行为。
- 不增加侧栏、文件树、编辑器、权限确认、命令面板或运行中切换 Provider。
- 不改变工具结果的截断上限、错误结构或安全参数摘要数据来源。
- 不实现会话持久化、搜索历史、主题切换或多窗口布局。
- 不增加网页界面、浏览器资源或外部 UI 依赖。

## 验收标准

- AC1: 连续发送至少三条用户消息时，每条消息均以独立高亮块显示，用户可一眼区分每轮问题与其后续回复。(F1)
- AC2: 助手文本、工具调用、工具结果、错误和取消提示具有可观察且一致的不同样式，终端主时间线仍易读。(F2)
- AC3: 工具调用结束后默认仅显示工具名、状态和安全摘要；点击工具行可展开结果摘要，再次点击可收起。`bash` 显示命令，写文件工具不显示写入正文。(F3, N4)
- AC4: 输入区始终位于底部，支持多行输入；正常结束、错误和取消后均恢复可编辑并获得焦点。(F4)
- AC5: 用户查看日志底部时流式回复自动跟随；用户向上滚动后继续产生回复或工具结果，阅读位置保持不变；回到底部后重新跟随。(F5)
- AC6: 流式回复、工具运行、完成、错误与取消时，临时活动区正确显示并在回合结束后清空，最终内容顺序不变。(F6, F7)
- AC7: 现有普通对话、多轮工具调用、计划模式、`/do`、取消和状态栏 token 统计的自动化测试全部通过。(F7, N6)
- AC8: 在窄终端与常见桌面终端宽度下观察，文本不覆盖输入区或状态栏，长工具输出默认不会撑开主时间线。(N1, N3)
