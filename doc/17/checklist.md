# 微信 4.0.5.15 单版本兼容 Checklist

状态：已批准（第二次修订）

> 每项必须通过运行代码或观察真实客户端验证；没有证据的项目不得标记完成。

## Implementation Completeness

- [ ] 唯一兼容版本是 4.0.5.15，默认客户端接受该版本。（验证：版本门禁单元测试）
- [ ] 4.1.12.55 和任意其他版本被拒绝，错误同时显示唯一支持版本和实际版本。（验证：版本门禁单元测试）
- [ ] `--probe` 帮助文本从运行时版本真源生成并显示 4.0.5.15。（验证：运行 CLI 帮助）
- [ ] 窗口发现、精确搜索、唯一结果、聊天标题复核和安全发送校验均被保留。（验证：代码差异审查和既有测试）
- [ ] `biubiubiu仿生人 1条未读 你好 21:38` 被规范化为联系人 `biubiubiu仿生人` 和未读数 `1`。（验证：会话解析单元测试）
- [ ] 通用 `session_item` 不阻止会话切换，切换仍经过精确搜索、唯一结果和聊天标题复核。（验证：会话切换单元测试）
- [ ] AutomationId 为空的精确联系人搜索结果可以被唯一识别。（验证：搜索切换单元测试）
- [ ] 搜索结果为零或存在多个精确同名结果时安全失败，不按 Enter 切换。（验证：搜索边界单元测试）
- [ ] UIA 观察失败日志包含异常类型和具体受控原因。（验证：机器人观察日志单元测试）
- [ ] README 和示例配置只向用户声明支持 4.0.5.15。（验证：限定范围文本搜索）

- [ ] 没有新增运行时或开发依赖。（验证：依赖文件差异审查）

## End-to-End Scenarios

- [ ] 场景 1：运行 `mewcode-wechat --help`，帮助只声明 4.0.5.15。（验证：命令输出）
- [ ] 场景 2：当前已登录微信为 4.0.5.15，并打开普通好友聊天页；运行 `mewcode-wechat --probe` 后输出版本、唯一主窗口、会话列表、消息列表和输入框，且不发送消息。（验证：真实只读命令输出）
- [ ] 场景 3：内存假窗口报告 4.1.12.55；客户端在访问控件前安全拒绝，并明确提示仅支持 4.0.5.15。（验证：自动化测试）
- [ ] 场景 4：白名单联系人在 4.0.5.15 中产生“`N条未读`”会话项；监听器识别精确联系人和未读消息，不因组合可访问名称跳过。（验证：内存集成测试；真实消息由用户手动发送）
- [ ] 场景 5：4.0.5.15 搜索返回一个 AutomationId 为空、显示名精确匹配的联系人；系统进入该聊天并复核标题，输入框临时写入后清空，全程不发送。（验证：真实 UIA 测试）
- [ ] 场景 6：UIA 搜索失败；日志显示 `WechatUiaError` 及“未找到微信好友”等具体原因，观察循环继续运行。（验证：自动化测试）
